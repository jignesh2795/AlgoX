# Knowledge Graph Promotion Gate

The AlgoX graph is currently a **logical derived projection**, not an authoritative database.

## Required workloads

1. contradiction discovery
2. supersession chains
3. project → capability → evidence traversal
4. experiment → result → finding → decision traversal
5. temporal path validity
6. provenance reconstruction
7. graph rebuild from authoritative records

## Promotion rule

A dedicated graph database is considered only if it provides a material improvement on relevant multi-hop workloads while preserving:

- provenance
- temporal correctness
- contradiction visibility
- deterministic reconstruction
- rebuildability
- write consistency
- operational simplicity appropriate to AlgoX's scale

A graph database is not selected merely because the data can be represented as a graph.
