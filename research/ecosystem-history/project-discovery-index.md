## Research policy

For each project, AlgoX should capture:

1. first meaningful public release / research date;
2. historical importance;
3. repository activity at the time studied;
4. architecture;
5. algorithms/capabilities;
6. data model;
7. interfaces and provider boundaries;
8. tests and evaluation;
9. failure modes;
10. production evidence;
11. license;
12. dependencies;
13. evolution over time;
14. relevant experiments;
15. extracted reusable capabilities;
16. evidence maturity;
17. AlgoX decision: ADOPT / ADAPT / WRAP / BUILD / REJECT.

## Discovery rule

Historical discovery is a separate phase from synthesis:

```text
Historical GitHub / Papers / Docs
          ↓
Project Discovery Index
          ↓
Project Records
          ↓
Capability Extraction
          ↓
Cross-project Comparison
          ↓
Contradiction / Gap Analysis
          ↓
Year Synthesis
```

Do not close a year merely because the current shortlist appears coherent. Newly discovered projects can QUALIFY, SUPERSEDE or REFUTE the provisional synthesis.
