# PX-2023-034 — CCXT

## Historical role
CCXT is a long-running unified API for cryptocurrency exchanges. Its 2023 architecture exposed a common Exchange base abstraction with exchange-specific implementations, separating public/private APIs while normalizing common operations. A versioned October 2023 manual snapshot documents the structure and the shared methods inherited by exchange classes. citeturn1search16

## Architecture observations
- Exchange-specific APIs are hidden behind a common interface.
- Public market-data operations and private trading/account operations are distinct capability surfaces.
- Normalization is useful for portability but cannot eliminate exchange-specific semantics.
- The abstraction is reusable for data acquisition, analytics and algorithmic trading, not only order placement.

## AlgoX extraction
**Capability:** unified exchange API with explicit adapter-specific escape hatches.

**Lesson:** an abstraction layer should normalize the common denominator while preserving access to venue-specific features. Over-normalization can silently discard important execution semantics.

## Decision
ADOPT as a reference pattern for adapter architecture; do not assume normalized APIs provide identical execution semantics across venues.
