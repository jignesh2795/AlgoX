## Why it belongs in the 2023 corpus

Semantic Kernel is a significant early framework for combining models with
plugins/functions, planning and application state. It is valuable for studying
how model reasoning can be bounded by explicit application capabilities.

- plugin/function abstraction
- planner architecture
- memory integration

- orchestration boundaries
- enterprise integration
- observability and safety controls

## AlgoX questions

1. How should model reasoning invoke deterministic domain functions?
2. What belongs in the model layer versus the application layer?
3. How can plugins expose capabilities without exposing unrestricted authority?
4. Which abstractions remain stable when providers change?
