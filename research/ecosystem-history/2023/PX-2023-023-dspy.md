# PX-2023-023 — DSPy

## Historical role
DSPy was introduced in October 2023 as a programming model for LM pipelines. Instead of treating prompts as fixed strings, it represented pipelines as declarative modules and introduced compilation/optimization against a metric. citeturn1academia12

## Architecture observations
- LM applications can be represented as composable programs rather than prompt collections.
- Optimization can target an explicit metric rather than relying only on manual prompt iteration.
- Retrieval, reasoning, prompting, and agent loops can become components of an optimizable pipeline.
- This creates a bridge between software engineering and empirical model optimization.

## Research value
Very high for AlgoX because it introduces a measurable distinction between **prompt text** and **program structure + optimization objective**.

## AlgoX extraction
**Potential capability:** declarative research pipelines with metric-driven optimization.

**Lesson:** AI workflow quality should be evaluated against explicit objectives. A prompt or agent configuration is an implementation choice, not the research result.

## Evidence
