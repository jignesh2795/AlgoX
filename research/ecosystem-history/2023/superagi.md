# SuperAGI

- **Period:** 2023
- **Category:** Agent framework / platform
- **Historical signal:** A dev-first autonomous-agent framework that moved beyond a single agent loop toward provisioning, tools, workflows, memory, telemetry, and an operator interface.
- **Architecture lesson:** Agent systems benefit from explicit infrastructure around the model: tools, memory, workflows, deployment, permissions, and telemetry.
- **Capabilities observed:** Concurrent agents, toolkits, GUI, action console, vector-database integrations, performance telemetry, token controls, memory, and workflows.
- **AlgoX extraction:** Treat the agent as a system composed of model, tool layer, state/memory, execution control, observability, and operator controls.
- **Caution:** Feature breadth does not establish production reliability; each capability needs independent evaluation.
