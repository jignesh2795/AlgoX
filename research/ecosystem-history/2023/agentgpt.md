# AgentGPT

- **Period:** 2023
- **Category:** Browser-based autonomous agents
- **Historical signal:** Early effort to make autonomous-agent configuration and deployment accessible through a browser interface.
- **Core idea:** Configure an agent around a goal and let it execute a sequence of actions using an LLM-based loop.
- **Architecture lesson:** Separating agent configuration/UI from the execution loop helped turn an agent experiment into an accessible application.
- **AlgoX extraction:** Agent configuration surface; user-controlled goals; web UI as an operator layer.
- **Risk lesson:** Autonomous execution requires explicit limits, observability, permissions, and termination controls.
