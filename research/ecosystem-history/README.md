# AI-Era Ecosystem Archive

This archive records the evolution of the open-source technology ecosystem from **January 2023 onward**, with particular attention to the generative-AI and agent era.

## Research rule

A project being popular is a signal for investigation, not evidence that it is technically superior.

## Per-year structure

- `2023/` — early generative AI, LLM applications, RAG, agents, AI coding
- `2024/` — local models, RAG maturation, multimodal systems, agent frameworks
- `2025/` — MCP, coding agents, memory, computer use, agentic development
- `2026/` — AI-native software engineering, persistent agents, agent infrastructure, routing, emerging architectures

## Project lifecycle categories

`TRENDING`, `BREAKOUT`, `SUSTAINED`, `FALLEN`

## Required analysis

For significant projects capture trend evidence, historical state, problem solved, capabilities, architecture, design patterns, developer workflow, limitations, ecosystem influence, maintenance evolution, replacements, and reusable lessons.

## Historical principle

Always distinguish what was known at the time from what is known retrospectively. Preserve dates, versions, releases, commits, and source snapshots where practical.
