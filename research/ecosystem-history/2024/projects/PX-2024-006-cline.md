# PX-2024-006 — Cline

**Repository:** https://github.com/cline/cline
**Historical category:** AI-development / coding-agent
**Domain:** AI-assisted software engineering

## Historical signal
The 2024 coding-agent wave moved beyond code completion toward agents that inspect repositories, modify multiple files, execute commands, observe failures, and iterate with human approval.

## Capability observed
Cline's workflow combines repository context, tool execution, file diffs, command execution, browser access, approval boundaries, and explicit Plan/Act modes.

## Architectural lesson
An AI coding agent is better modeled as a controlled software-engineering workflow than as a text-generation feature. The environment, tools, state, verification, permissions, and human checkpoints are architectural components.

## AlgoX extraction
- Repository-aware context
- Tool execution
- Plan/Act separation
- Human-in-the-loop approval
- Diff/checkpoint model
- Iterative verification
- Model-provider abstraction
- Agent rules/skills

## Relevance to AlgoX
Highly relevant to the research-engineering side of AlgoX. Future research agents should operate through explicit tools, evidence capture, verification, and bounded permissions rather than unrestricted autonomous prompting.
