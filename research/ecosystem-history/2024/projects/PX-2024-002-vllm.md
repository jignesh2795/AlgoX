# PX-2024-002 — vLLM

**Repository:** https://github.com/vllm-project/vllm
**Historical category:** FOUNDATIONAL infrastructure
**Domain:** LLM inference / serving

## Historical signal
vLLM originated from the 2023 PagedAttention research and became a major open-source serving layer as the ecosystem matured. Its core contribution was treating LLM inference as a systems problem involving KV-cache memory management and high-throughput scheduling.

## Capability observed
The architecture separates model serving from applications through a high-performance runtime and API boundary. Important systems techniques include PagedAttention, continuous batching, chunked prefill, prefix caching, quantization, streaming, parallelism, structured outputs, and tool calling.

## Architectural lesson
Inference should be treated as infrastructure with explicit resource-management and scheduling concerns, not as a thin wrapper around model generation.

## AlgoX extraction
- Dedicated model-serving layer
- Memory-aware inference
- Continuous batching
- API compatibility boundary
- Hardware abstraction
- Structured-output enforcement
- Tool-calling boundary
- Performance benchmarking as an infrastructure concern

## Relevance to AlgoX
Important precedent for separating AI inference infrastructure from domain systems. A future trading platform should be able to swap model-serving implementations without coupling financial-domain logic to a specific inference runtime.
